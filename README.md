# 🏡 WanderLust – Travel & Property Listing Platform

WanderLust is a full-stack web application inspired by travel and property-booking platforms. It allows users to explore property listings, create their own listings, upload images, manage listings, and view locations on an interactive map.

The project is built using the **MERN/Node.js ecosystem**, with **Express.js, MongoDB, Mongoose, EJS, Cloudinary, and Mapbox**.

---

## 🚀 Features

* 🔐 User registration and login
* 👤 User authentication and authorization
* 🏠 Create new property listings
* ✏️ Edit and update listings
* 🗑️ Delete listings
* 📷 Upload property images
* ☁️ Cloudinary image storage
* 🗺️ Interactive Mapbox maps
* 📍 Display property locations
* ⭐ Listing details and information
* 💬 Flash messages for success/error notifications
* 🛡️ Protected routes and ownership authorization
* 📱 Responsive user interface
* 💾 MongoDB database integration
